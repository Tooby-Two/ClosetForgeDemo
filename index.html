    Installing the mod

    Anything you do between dumping the save file and installing the modified one will be lost! Extract the .zip file from the site first. Then follow the steps for where you play.

    Switch hardware
    1. Connect your Switch's SD card to your PC, either physically, through USB file transfer, or an FTP server.
    2. Copy the ClosetForge_Mod\romfs folder from the extracted .zip file into atmosphere\contents\010051f0207b2000\ on your Switch's SD card. You don't need the exefs folder, as the file in there is for Ryujinx users. It won't crash your game if you leave it, however.
    3. Copy the contents of ClosetForge_OfficialHardware to the root of your SD card. This is important! This contains the exefs patch that is required to run the mod.
    4. Find your extracted save file. If using JKSV, this will be under JKSV\Tomodachi Life Living the Dream\. Make sure to back up your original save file somewhere safe!
    5. Extract the .zip file of the save you wish to edit, then copy Player.sav and the Ugc\ folder from the Closet Forge Demo .zip file into your extracted save file.
    6. Re-zip the save file directory on your PC. You can do this on Windows by selecting every file in your save directory, right-clicking the selected files, and selecting "Compress To -> ZIP File".
    7. Copy the modified save .zip file onto your SD card. If using JKSV, place the .zip file in JKSV\Tomodachi Life Living the Dream\ so that JKSV can read it.
    8. Disconnect your Switch's SD card from your PC.
    9. Use a save manager application like JKSV to restore the modified save file onto your Switch. If using JKSV, go to the application, select the user with the save file you wish to replace, select Tomodachi Life: Living the Dream, and select the modified save file .zip to restore to the game.
    10. Launch Tomodachi Life: Living the Dream.
    Ryujinx
    1. Open your Atmosphere mod directory. You can easily find this by opening Ryujinx, right-clicking Tomodachi Life: Living the Dream, and pressing "Open Atmosphere Mod Directory".
    2. Place the ClosetForge_Mod\ folder from the extracted .zip file into your Atmosphere mod directory.
    3. Open your save file location. You can easily find this by opening Ryujinx, right clicking Tomodachi Life: Living the Dream, and pressing "Open User Save Directory".
    4. Back up your original Player.sav file somewhere safe in case something breaks!
    5. Copy the Player.sav file and the Ugc\ folder from the extracted .zip file into the root of your save directory.
    6. Launch Tomodachi Life: Living the Dream.
