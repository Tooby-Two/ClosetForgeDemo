What gets added

They go into the next six free closet slots in your save, so nothing already in your save is touched.

1

Game files

Open your game dump's romfs folder and select these six files together. These need to be from the 1.0.4 update!

Drop the six game files here or click to choose

    Need help with dumping your romfs?
    You'll first need an emulator like Ryujinx. For Ryujinx users, load Tomodatchi Life: Living the Dream with the 1.0.4 save into the emulator, right-click on the game on the home screen, and go to to "Extract Data", then "RomFS". Choose a location for the game to put the dumped files. This will take a while!

    2

    Your save file

    Drop your Player.sav. The six new items go into the next free closet slots, so your original clothes are not touched.
    The mod comes exported with a new save file, so you won't lose your original save.

    Build

    1. Copy the ClosetForge_Mod folder into /contents/010051F0207B2000/.
    2. Back up your save file!
    3. Copy Player.sav and the Ugc/ folder from the exported .zip file into your save directory.
      For offical Switch hardware, I recommend using JKSV to back up and edit your save file.
